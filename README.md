# CinePlayer Pro

Base inicial do player IPTV para Android, Android TV e TV Box.

Tecnologias: Kotlin, Jetpack Compose e Android Media3 ExoPlayer.

Próximas etapas:
- parser M3U real para arquivo e URL;
- grupos, busca e favoritos;
- EPG/XMLTV opcional;
- navegação por controle remoto;
- filmes e séries;
- múltiplas playlists;
- testes e geração do APK.

Use somente playlists e conteúdos para os quais você tenha autorização de uso.
